  The editor has four parts: the **content** you put in, the **state** you

  and you know the editor.

<h2 id="value">1. Content in</h2>

You can start an editor from markdown, from a saved document, or empty:

<FrameworkTabs>

```ts
import { createEditor, createDoc } from "@tasfer/editor";

// from markdown
createEditor({ element, markdown: "# Title" });

// from a saved document
const doc = createDoc(savedBytes);
createEditor({ element, doc });

// empty
createEditor({ element });
```

```tsx
import { Editor, useEditor } from "@tasfer/react";
import { createDoc } from "@tasfer/editor";

// from markdown
<Editor markdown="# Title" />;

// from a saved document
const doc = createDoc(savedBytes);
<Editor doc={doc} />;

// empty
<Editor />;

// or the hook, when you want to own the element yourself
const { containerRef, editor } = useEditor({ markdown: "# Title" });
```

</FrameworkTabs>

<h2 id="state">2. State out</h2>

<ForFramework fw="js">

`editor.state` tells you what is selected and which marks are active. It is a snapshot: every edit makes a new one. So read `editor.state` when you need it, and do not keep an old copy.

</ForFramework>

<ForFramework fw="react">

`useEditorState(editor)` tells you what is selected and which marks are active. Your component re-renders when that changes, so a toolbar stays up to date on its own. It is `null` until the editor exists.

</ForFramework>

<FrameworkTabs>

```ts
const { selection, activeMarks, doc } = editor.state;

selection.empty;              // true when nothing is selected
activeMarks.has("strong");    // is bold on at the caret?
```

```tsx
import { useEditorState } from "@tasfer/react";

const state = useEditorState(editor);
const active = state?.activeMarks ?? new Set();

state?.selection.empty;   // true when nothing is selected
active.has("strong");     // is bold on at the caret?
```

</FrameworkTabs>

<h2 id="commands">3. Changes</h2>

You do not edit the document directly. You call `change` and make your edits inside it:

```ts
editor.change((c) => c.setMark("strong"));
editor.change((c) => c.setBlock({ type: "heading", level: 2 }));

// several edits, one undo step
editor.change((c) =>
  c.setMark("strong").setMark("emphasis").insertText(" ✶"),
);
```

Everything inside one `change` call is one undo step. `change` returns `true` when something changed.

<ForFramework fw="react">

React has no separate API for this. Call `change` on the `editor` you get from `useEditor` or `onReady`, straight from an `onClick`.

</ForFramework>

Every edit you can make is listed on [Changes & actions](/docs/editor/api-commands).

<h2 id="events">4. Events</h2>

<PropsTable cols={["Event", "Payload", "Fires when"]} rows={[
  { name: "change", type: "ChangeTransaction", desc: "The document changed: typing, paste, undo, or an edit from another person." },
  { name: "selectionchange", type: "EditorStateSnapshot", desc: "The caret or selection moved, and the document did not change." },
  { name: "focus / blur", type: "EditorStateSnapshot", desc: "The editor gained or lost focus." },
]} />

<ForFramework fw="js">

`editor.on` subscribes, and returns a function that unsubscribes.

</ForFramework>

<ForFramework fw="react">

Subscribe in a `useEffect` and return what `editor.on` gives you as the cleanup. Use this for side effects like saving. To re-render on edits, use `useEditorState` or `useEditorMarkdown`.

</ForFramework>

<FrameworkTabs>

```ts
const off = editor.on("change", (tx) => {
  if (tx.isRemote) return;          // skip edits from other people
  console.log("local edit:", tx.ops.length, "ops");
});

// later
off();
```

```tsx
useEffect(() => {
  if (!editor) return;
  return editor.on("change", (tx) => {
    if (tx.isRemote) return;          // skip edits from other people
    console.log("local edit:", tx.ops.length, "ops");
  });
}, [editor]);
```

</FrameworkTabs>

Connection status and the number of people online are not editor events. They come from the provider. See [Collaboration](/docs/editor/collaboration).
