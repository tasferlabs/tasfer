<h2 id="mount">Step 1. Mount the editor</h2>

The editor fills its container, so the container needs a height.

<ForFramework fw="js">

Give `createEditor` an element. You get back `editor`, which every later step uses. Call `editor.destroy()` when the page goes away.

</ForFramework>

<ForFramework fw="react">

`useEditor` creates the editor once and cleans it up for you. It gives you a `containerRef` to put on a div, and `editor`, which every later step uses.

</ForFramework>

<FrameworkTabs>

```ts file="main.ts"
import { createEditor } from "@tasfer/editor";

// <div id="editor" style="height: 70vh"></div>
const editor = createEditor({
  element: document.querySelector("#editor")!,
  markdown: "# My notes\n\nWrite something.",
  placeholder: "Start writing…",
  autofocus: true,
});
```

```tsx file="App.tsx"
import { useEditor } from "@tasfer/react";

export default function App() {
  const { containerRef, editor } = useEditor({
    markdown: "# My notes\n\nWrite something.",
    placeholder: "Start writing…",
    autofocus: true,
  });

  return <div ref={containerRef} style={{ height: "70vh" }} />;
}
```

</FrameworkTabs>

<h2 id="toolbar">Step 2. Add a toolbar</h2>

The toolbar does not remember formatting itself. It asks the editor: read `activeMarks` to highlight a button, and call `change` on click.

<ForFramework fw="js">

Nothing repaints the buttons for you. Run `paint()` on both `change` and `selectionchange`, because moving the caret also changes which marks are active.

</ForFramework>

<ForFramework fw="react">

`useEditorState` re-renders the toolbar on edits and on caret moves, so there is nothing to subscribe to.

</ForFramework>

<FrameworkTabs>

```ts file="main.ts"
const toolbar = document.querySelector("#toolbar")!;

const buttons = ([
  { label: "B", mark: "strong" },
  { label: "i", mark: "emphasis" },
  { label: "</>", mark: "code" },
] as const).map((b) => {
  const el = document.createElement("button");
  el.textContent = b.label;
  el.onclick = () => editor.change((c) => c.setMark(b.mark));
  toolbar.append(el);
  return { ...b, el };
});

function paint() {
  const active = editor.state.activeMarks;
  for (const b of buttons) {
    b.el.classList.toggle("is-active", active.has(b.mark));
  }
}
editor.on("change", paint);
editor.on("selectionchange", paint);
paint();
```

```tsx file="Toolbar.tsx"
import { useEditorState, type TasferEditor } from "@tasfer/react";

const MARKS = [
  { label: "B", mark: "strong" },
  { label: "i", mark: "emphasis" },
  { label: "</>", mark: "code" },
] as const;

export function Toolbar({ editor }: { editor: TasferEditor | null }) {
  const active = useEditorState(editor)?.activeMarks ?? new Set();
  return (
    <div>
      {MARKS.map((b) => (
        <button
          key={b.mark}
          className={active.has(b.mark) ? "is-active" : ""}
          onClick={() => editor?.change((c) => c.setMark(b.mark))}
        >
          {b.label}
        </button>
      ))}
    </div>
  );
}
```

</FrameworkTabs>

<ForFramework fw="react">

Put `<Toolbar editor={editor} />` above the editor's div. `editor` is `null` on the first render, and the toolbar handles that.

</ForFramework>

<Callout kind="tip" title="Markdown shortcuts are already on.">Type `**bold**`, `## ` at the start of a line, or `- ` for a bullet. Select some text and type `*` to make it italic. For formulas, add the [math extension](/docs/editor/api-schema#math).</Callout>

<h2 id="persist">Step 3. Save locally</h2>

Save the document as markdown every time it changes, and load it back on start. That is enough for one device.

<ForFramework fw="react">

Do it in an effect, and return what `editor.on` gives you as the cleanup:

</ForFramework>

<FrameworkTabs>

```ts file="main.ts"
// load
const saved = localStorage.getItem("draft");
if (saved) editor.setMarkdown(saved);

// save; `change` fires on every edit, so debounce this if it is too much
editor.on("change", (tx) => {
  if (tx.isRemote) return;
  localStorage.setItem("draft", editor.getMarkdown());
});
```

```tsx file="App.tsx"
import { useEffect } from "react";

// inside App, after useEditor(...)
useEffect(() => {
  if (!editor) return;

  // load
  const saved = localStorage.getItem("draft");
  if (saved) editor.setMarkdown(saved);

  // save; `change` fires on every edit, so debounce this if it is too much
  return editor.on("change", (tx) => {
    if (tx.isRemote) return;
    localStorage.setItem("draft", editor.getMarkdown());
  });
}, [editor]);
```

</FrameworkTabs>

<h2 id="collab">Step 4. Edit together</h2>

To let people edit together, add a provider. A provider sends edits between people. Nothing from the steps above changes.

Open the page in two tabs and type.

<ForFramework fw="react">

Create the provider in an effect, keep its status in state, and `destroy()` it on unmount:

</ForFramework>

<FrameworkTabs>

```ts file="main.ts"
import { createRelayProvider } from "@tasfer/provider-relay";

const status = document.querySelector("#status")!;

const provider = createRelayProvider({
  doc: editor.doc,                      // this editor's document
  room: "my-notes-demo",                // same room, same document
  relay: "wss://relay.tasfer.app",      // demo relay; run your own for real work
  secret: "change-me-before-you-ship",  // room password; never give it to the relay
});

// connection status comes from the provider, not the editor
provider.on("sync", (s) => {
  status.textContent = s.connected ? `live · ${s.peers} peer(s)` : "offline";
});
```

```tsx file="App.tsx"
import { useState, useEffect } from "react";
import { createRelayProvider } from "@tasfer/provider-relay";

// inside App
const [status, setStatus] = useState("offline");

useEffect(() => {
  if (!editor) return;
  const provider = createRelayProvider({
    doc: editor.doc,                      // this editor's document
    room: "my-notes-demo",                // same room, same document
    relay: "wss://relay.tasfer.app",      // demo relay; run your own for real work
    secret: "change-me-before-you-ship",  // room password; never give it to the relay
  });
  // connection status comes from the provider, not the editor
  provider.on("sync", (s) =>
    setStatus(s.connected ? `live · ${s.peers} peer(s)` : "offline"),
  );
  return () => provider.destroy();
}, [editor]);
```

</FrameworkTabs>

<Callout kind="warn" title="The relay cannot read your document.">Edits are encrypted with a key made from `secret` before they leave the browser. So share the secret with people yourself, for example in an invite link, and never send it to the relay. The relay still sees the room name, who is connected, and when they send. [Realtime collaboration](/docs/editor/collaboration) has the details.</Callout>
