  `@tasfer/editor` is the editor from the Tasfer app, as a package you can put
  in your own app. It works with any framework. **It draws the text on a
  `<canvas>`, needs no server, and lets several people edit the same document
  at once, even offline.** Their changes merge when they reconnect.

<h3 id="extras">Optional packages</h3>

The big features are separate packages, so they stay out of your bundle until you ask for them:

- [`@tasfer/math`](/docs/editor/api-schema#math) and `@tasfer/tex`: formulas. Install both.
- [`@tasfer/code`](/docs/editor/api-schema#code): code blocks with syntax highlighting.
- [`@tasfer/table`](/docs/editor/api-schema#table): tables.
- [`@tasfer/provider-relay`](/docs/editor/collaboration): editing together over the network.

<h2 id="requirements">Requirements</h2>

A modern browser, meaning any browser updated since about 2020.

Nothing else. No server, no extra files to host, no bundler plugin. You can also create and read documents in Node, without a browser.

<h2 id="first">A 30-second editor</h2>

The smallest thing that works: a document you can type in, with markdown shortcuts and undo.

<ForFramework fw="js">

Mount the editor into an element on your page, and read the document back as markdown when it changes:

</ForFramework>

<ForFramework fw="react">

Render the `<Editor>` component. It reports every edit through `onChange`:

</ForFramework>

<FrameworkTabs>

```ts file="main.ts"
import { createEditor } from "@tasfer/editor";

const editor = createEditor({
  element: document.querySelector("#editor")!,
  markdown: "# Hello\n\nStart typing. *Markdown* shortcuts just work.",
  autofocus: true,
});

editor.on("change", () => {
  localStorage.setItem("draft", editor.getMarkdown());
});
```

```tsx file="App.tsx"
import { Editor } from "@tasfer/react";

export default function App() {
  return (
    <Editor
      markdown={"# Hello\n\nStart typing. *Markdown* shortcuts just work."}
      autofocus
      style={{ height: "70vh" }}
      onChange={(markdown) => localStorage.setItem("draft", markdown)}
    />
  );
}
```

</FrameworkTabs>

<Callout kind="tip" title="Collaboration can wait.">You do not have to plan for it now. When you want people to edit together, you [add a provider](/docs/editor/collaboration) and keep everything you already built.</Callout>
