<h2 id="what">ما هو؟</h2>

يشغّل `tasfer host` التطبيقَ بلا واجهة: نموذج المستندات نفسه، وبنية CRDT نفسها،
وبروتوكول الاتصال نفسه — موصولةً بقاعدة SQLite ومقابس Node بدل المتصفح. تربطه
كما تربط هاتفًا، فيصبح منذئذٍ واحدًا من أجهزتك. أغلق حاسوبك في منتصف جملة؛
فالجملة عند المُضيف بالفعل، ومنه يأخذها هاتفك.

ما الذي يمنحك إياه؟

- **تقارب بلا موعد.** تتزامن أجهزتك عبر نظير لا ينقطع، بدل انتظار لحظة تكون فيها كلها متصلة.
- **نسخة تخصّك.** نسخة احتياطية تحزمها وتستعيدها، على عتاد تختاره بنفسك.
- **لا طرف جديد تثق به.** يُسجَّل تحت هويتك كأي جهاز آخر — لا حساب، ولا خدمة، ولا طرف ثالث.

<Callout kind="warn" title="المُضيف هو الحساب.">يسلّم الربطُ الآلةَ هويتك الجذرية وكل مساحاتك، بما فيها الخاصة. شغّله في مكان لا يصل إليه غيرك: جهازك أنت، بقرص مشفّر بالكامل، لا على خادم مشترك.</Callout>

<h2 id="install">التثبيت</h2>

Node 22 أو أحدث، ثم ابنِ الأداة من المستودع:

```bash
cd apps/cli
npm install
npm run build
npm link          # optional — puts `tasfer` on your PATH
```

الحزمة `node-datachannel` اختيارية: بوجودها ينشئ المُضيف اتصالات WebRTC مباشرة
كسائر الأجهزة. وبدونها — على منصة لا تتوفر لها نسخة مبنية مسبقًا — تستمر
المزامنة عبر مسار المُرحِّل الذي يلجأ إليه التطبيق أصلًا. وفي الحالتين يُشفَّر
كل شيء قبل أن يغادر الآلة.

<h2 id="link">اربطه بحسابك</h2>

<Steps>
  <Step title="احصل على رمز من التطبيق">
    من جهاز تستخدمه بالفعل، افتح **الملف الشخصي ← ربط جهاز** وانسخ الرمز.
  </Step>
  <Step title="سلّم الرمز للمُضيف">
    ```bash
    tasfer host link <code> --name "basement box"
    ```
    أبقِ التطبيق مفتوحًا حتى يعلن اكتمال الربط — لا بد أن يلتقي الطرفان.
  </Step>
  <Step title="شغّله">
    ```bash
    tasfer host
    ```
    صار المُضيف متصلًا ويزامن. ويخبرك `tasfer host status` بما يحتفظ به.
  </Step>
</Steps>

ويمكنك البدء من جهة المُضيف أيضًا: يطبع `tasfer host invite` رمزًا تلصقه في
**إدخال رمز من جهاز آخر** داخل التطبيق. المصافحة نفسها، في الاتجاه المعاكس.

<Callout kind="note" title="أمر واحد في كل مرة.">كل أمر يفتح قاعدة البيانات نفسها. أوقف المُضيف قبل الربط، حتى لا تعيد المصافحةُ كتابةَ هوية تجري تحتها مزامنة.</Callout>

<h2 id="service">أبقه يعمل</h2>

المُضيف عملية عادية في المقدمة تتوقف عند `SIGINT`/`SIGTERM`، فأي مشرف عمليات
يفي بالغرض. وهذه وحدة systemd:

```ini
[Unit]
Description=Tasfer host
After=network-online.target

[Service]
ExecStart=/usr/bin/tasfer host
Restart=on-failure
User=tasfer

[Install]
WantedBy=multi-user.target
```

<h2 id="backup">خذ نسخة احتياطية</h2>

كل شيء في مجلد البيانات: ملف `tasfer.db` وملفات المرفقات بجواره. أوقف المُضيف،
وانسخ المجلد، ثم أعد تشغيله. والاستعادة هي العملية نفسها معكوسة — تبقى النسخة
هي ذلك الجهاز، ومرتبطة كما كانت.

<Callout kind="note" title="ما لا يضيفه المُضيف.">لا حسابات، ولا معالجة على الخادم، ولا واجهة برمجية. لا يستطيع قراءة مساحة لم يُدعَ إليها، ولا يحمل مفتاحًا لا تحمله بقية أجهزتك.</Callout>
